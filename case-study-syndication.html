Designing Clearer Step-by-Step Workflows

Avestor Inc. — Complex Financial SaaS Product

Quick Summary

I redesigned the Avestor syndication setup workflow to address confusion and reduce friction for both syndication managers and investors. The goal was to streamline onboarding, improve clarity at each step, and reduce drop-off during the setup process.

Problem / Pain Points

  • Users lacked clear guidance through workflows
  • Inconsistent terminology created user insecurity and confusion
  • Lack of system feedback between user actions and next steps

Goals / Suggested Solutions

  • Create Clearer Workflows - Guide users through setup & registration process step-by-step
  • Implement Consistent Terminology - Use one clear name for each concept
  • Provide Responsive System Feedback - Clearly confirm actions & show workflow progress
